雙狹縫干涉互動展示頁面｜手機分享版

一、電腦直接使用
解壓縮後，用 Chrome、Edge 或 Safari 開啟 index.html，即可使用全部模擬功能。不需要安裝套件、不需要帳號，也沒有外部字型或程式依賴。
手機不建議從通訊軟體附件預覽 HTML；請使用發布後的 HTTPS 網址。

二、發布與分享
將此資料夾中的所有檔案上傳至支援靜態網站的空間，確保 index.html 位於網站根目錄（也支援子目錄）。不需要建置指令或後端伺服器。
例如：使用靜態網站託管服務的手動上傳功能，選擇本資料夾作為發布內容；或使用 GitHub Pages，把檔案放在選定分支的根目錄後啟用 Pages。
託管服務產生 HTTPS 網址後，把網址或其 QR code 分享給學生；學生用手機瀏覽器開啟即可。若服務設定為公開，其他人不必登入你的帳號。
壓縮檔本身不是公開網址，仍須上傳託管；原先的私人 Sites 網址不會因為此封裝而改為公開。

三、加入手機主畫面
iPhone／iPad：以 Safari 開啟發布後網址 → 分享 → 加入主畫面。
Android：以 Chrome 開啟發布後網址 → 選單 → 安裝應用程式或加入主畫面（依瀏覽器版本顯示）。
網站以 HTTPS 發布、首次完整載入且快取完成後，可離線使用模擬。瀏覽器可能清除快取，離線功能不是永久儲存保證。直接從 file:// 開啟不會啟用離線快取與網站安裝。

四、教學操作
可調整波長（380–750 nm）、狹縫中心間距（0.10–0.60 mm）與屏距（0.5–3.0 m）；提供紅綠藍預設、動畫暫停、光強度曲線、亮紋標記及重設。
手機可直向操作，橫向更適合觀察波紋。全螢幕功能依裝置瀏覽器支援狀況而定。

五、模型與驗證
以同相等振幅相干光、小角度遠場模型計算，忽略單縫繞射包絡。
Δy = λL/d；I/Imax = cos²(πdy/λL)。波紋圖採示意比例。
預設 λ=550 nm、d=0.25 mm、L=1.5 m，Δy=3.30 mm。
紅光改成650 nm時，Δy=3.90 mm；預設狹縫間距加倍至0.50 mm時，Δy=1.65 mm。
